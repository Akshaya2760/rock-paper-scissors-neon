# 🎮 Rock Paper Scissors — Neon Arena

A modern, interactive **Rock Paper Scissors** web game with an advanced neon arcade-style interface, AI opponent, animations, sound effects, scoring, achievements, statistics, and multiple game modes.

## ✨ Features

* 🪨 Rock, 📄 Paper, ✂️ Scissors gameplay
* 🤖 AI opponent with multiple difficulty levels
* 🎯 Classic, Best of 3, Best of 5 and Endless modes
* 🔥 Combo and win-streak system
* 🏆 Achievement system
* 📊 Player statistics
* 🥇 Local leaderboard
* ⚡ Power-ups and special rounds
* 🎵 Sound effects and background audio
* 🎨 Neon arcade-style UI
* ✨ Smooth animations and particle effects
* ⏱️ Animated countdown
* 👤 Player profile and XP system
* 📅 Daily challenges
* 💾 LocalStorage-based progress saving
* 📱 Responsive design for desktop, tablet and mobile
* ♿ Keyboard controls and accessibility features
* 🌙 Dark futuristic interface

## 🎮 Game Modes

### Classic

Play continuous rounds and try to achieve the highest score.

### Best of 3

The first player to win 2 rounds wins the match.

### Best of 5

The first player to win 3 rounds wins the match.

### Endless

Keep playing and build the highest possible score and streak.

### Challenge

The AI becomes progressively more challenging as the match continues.

## 🤖 AI Difficulty

| Difficulty | Description                                 |
| ---------- | ------------------------------------------- |
| Easy       | Mostly random choices                       |
| Normal     | Basic prediction                            |
| Hard       | Analyzes previous player choices            |
| Master     | Uses pattern analysis and adaptive strategy |

The AI is designed to remain unpredictable rather than winning every time.

## 🏆 Scoring System

| Result | Base Points |
| ------ | ----------: |
| Win    |        +100 |
| Draw   |         +25 |
| Loss   |          +0 |

Winning consecutive rounds activates the combo multiplier.

Example:

`🔥 Combo x2`

`🔥 Combo x3`

`🔥 Combo x4`

`🔥 Combo x5`

## 💾 Data Storage

Player data is stored locally using browser `localStorage`.

Stored information includes:

* Player name
* Avatar
* Scores
* Wins
* Losses
* Draws
* Win streak
* Highest combo
* Achievements
* XP and level
* Leaderboard
* Settings
* Daily challenge progress

No backend database is required for the basic version.

## 🚀 Running the Project

Clone the repository:

```bash
git clone https://github.com/Akshaya2760/rock-paper-scissors-neon.git
```

Open the project folder:

```bash
cd rock-paper-scissors-neon
```

Then open the application in a browser.

For development, it can also be served using a local development server such as VS Code Live Server.
